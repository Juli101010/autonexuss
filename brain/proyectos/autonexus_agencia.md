# Proyecto: Autonexus Agencia

## Estado

Activo / diseño inicial.

## Propósito

Construir la estructura operativa de Autonexus como agencia apoyada por inteligencia artificial, agentes virtuales, skills, memoria, grafo operativo, automatizaciones y control humano.

## Principio central

Dirección observa, decide, aprueba, rechaza, delega y bloquea.

Los agentes pueden analizar, proponer, crear borradores y ejecutar tareas de bajo riesgo, pero toda decisión sensible requiere aprobación de Dirección.

## Servicios principales de la agencia

- Implementación y soporte Odoo
- Automatizaciones con n8n
- CRM y WhatsApp
- Desarrollo web y paneles internos
- Integraciones entre sistemas
- Propuestas comerciales y documentación
- Auditorías técnicas
- Dashboards y control operativo
- Diseño de procesos con IA

## Primeros agentes necesarios

- Agente PM
- Agente Odoo
- Agente Comercial
- Agente QA
- Agente Documentador
- Agente Web/Dev
- Agente Automatizaciones

## Primeros skills necesarios

- Skill Propuesta Cliente
- Skill Auditoría Odoo
- Skill QA Preproducción
- Skill Cierre de Tarea
- Skill Crear Nuevo Agente

## Primeros procesos a construir

1. Nueva tarea → clasificación → agente → permiso → resultado → aprendizaje.
2. Lead → diagnóstico → propuesta → seguimiento.
3. Error técnico → diagnóstico → solución segura → QA → documentación.
4. Proyecto cliente → memoria → entregable → aprendizaje → actualización del grafo.
5. Proceso repetido → propuesta de nuevo skill → aprobación de Dirección.

## Riesgos iniciales

- Querer instalar demasiadas herramientas antes de tener procesos claros.
- Automatizar sin gobierno humano.
- Tocar producción sin permisos.
- Subir credenciales al repositorio público.
- Crear demasiados agentes sin necesidad real.
- No documentar aprendizajes.

## Regla de avance

Primero se arma el sistema operativo de trabajo.

Después se conectan herramientas.

Orden recomendado:

1. Gobierno
2. Permisos
3. Memoria
4. Tareas
5. Agentes
6. Skills
7. Grafo
8. GitHub
9. Claude Code / Codex
10. n8n
11. Ollama o modelos locales si realmente aportan
12. Panel vivo
