# Cliente Demo: Distribuidora Alfa

## Estado

Cliente ficticio de prueba.  
No corresponde a un cliente real.

## Tipo de empresa

Distribuidora mayorista con venta a comercios minoristas.

## Necesidad principal

Ordenar la gestión comercial, mejorar el seguimiento de clientes, centralizar productos, controlar listas de precios y preparar una futura integración entre ventas, facturación e inventario.

## Problemas actuales

- uso de planillas separadas
- dificultad para actualizar precios
- seguimiento comercial poco ordenado
- productos duplicados o mal cargados
- falta de trazabilidad entre pedido, presupuesto y venta
- reportes manuales
- baja visibilidad del estado de cada cliente

## Objetivo buscado

Implementar Odoo de manera progresiva, comenzando por CRM, Ventas, Productos y Clientes, dejando preparada una segunda etapa para Inventario, Facturación y reportes.

## Módulos iniciales sugeridos

- CRM
- Ventas
- Contactos
- Productos
- Listas de precios
- Reportes comerciales básicos

## Módulos para segunda etapa

- Inventario
- Facturación
- Compras
- Automatizaciones
- Dashboards

## Riesgos detectados

- datos actuales desordenados
- productos repetidos
- listas de precios no normalizadas
- falta de responsable interno
- necesidad de validar impuestos y facturación antes de operar en producción

## Recomendación inicial

Comenzar con una Fase 1 de relevamiento y normalización de datos comerciales antes de activar procesos sensibles como facturación o inventario real.
