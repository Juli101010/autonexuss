# Brain de Autonexus

Esta carpeta guarda la memoria operativa de la agencia.

## Qué guardar

- clientes
- proyectos
- errores aprendidos
- decisiones
- procesos
- skills detectadas
- memoria marrón

## Regla

Todo error resuelto debe convertirse en aprendizaje.
Todo proceso repetido más de tres veces debe proponerse como skill.
