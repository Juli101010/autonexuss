# Autonexus OS v0.1

Sistema operativo inicial para una agencia con gobierno humano, agentes virtuales, skills, memoria, grafo operativo, automatización futura y visualización 3D.

## Idea central

Los agentes trabajan.  
Las herramientas ejecutan.  
La memoria aprende.  
El grafo muestra relaciones, riesgos, permisos, resultados y consecuencias.  
Dirección observa y decide.

## Cómo empezar

1. Abrir esta carpeta en VS Code.
2. Leer `CLAUDE.md`, `GOVERNANCE.md`, `PERMISSIONS.md` y `TASK_PROTOCOL.md`.
3. Abrir `ui/grafo_3d_demo.html` en el navegador para ver la demo visual.
4. Editar `graph/nodes.json` y `graph/edges.json` para agregar nodos reales.
5. Guardar aprendizajes, clientes, proyectos y decisiones dentro de `brain/`.

## Reglas de seguridad

- No tocar producción sin aprobación de Dirección.
- No enviar propuestas finales sin aprobación.
- No usar credenciales sensibles sin permiso.
- No crear agentes nuevos sin aprobación.
- No activar automatizaciones reales sin revisión.
