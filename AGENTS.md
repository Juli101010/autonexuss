# Mapa inicial de agentes de Autonexus OS

## Agentes base

1. Agente PM
2. Agente Odoo
3. Agente Comercial
4. Agente QA
5. Agente Documentador
6. Agente Web/Dev
7. Agente Automatizaciones

## Regla de creación de nuevos agentes

Un agente no puede crear otro agente directamente.

Puede proponerlo con este formato:

- Nombre del agente propuesto
- Motivo
- Problema que resuelve
- Skills que necesita
- Permisos solicitados
- Riesgos
- Límites
- Aprobación requerida por Dirección
