# Skill Crear Nuevo Agente


Permite proponer un nuevo agente, pero no activarlo sin Dirección.

## Formato de propuesta

- nombre del agente
- problema que resuelve
- tareas que asumiría
- skills requeridos
- permisos solicitados
- límites
- riesgos
- relación con otros agentes
- motivo para crearlo ahora
- aprobación requerida
