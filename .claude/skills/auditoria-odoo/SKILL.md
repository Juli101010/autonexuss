# Skill Auditoría Odoo


Procedimiento para diagnosticar problemas Odoo.

## Pasos

1. Identificar versión, base y empresa.
2. Leer síntoma exacto.
3. Identificar módulos afectados.
4. Revisar logs.
5. Revisar modelos, vistas, datos y permisos.
6. Si afecta facturación argentina, revisar AFIP, diarios, puntos de venta, impuestos y secuencias.
7. Proponer corrección en rama segura.
8. Validar con QA.
9. Documentar error aprendido.

## Requiere aprobación

Siempre antes de tocar producción, base real o credenciales.
