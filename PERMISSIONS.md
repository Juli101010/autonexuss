# Sistema de Permisos Autonexus OS

## Nivel 0 — Lectura y análisis

Puede hacerse sin pedir permiso:

- leer archivos internos autorizados
- resumir información
- clasificar tareas
- detectar riesgos
- sugerir próximos pasos

## Nivel 1 — Creación de borradores

Puede hacerse sin aprobación previa:

- crear borradores
- proponer documentos
- redactar ideas
- generar diagnósticos
- armar checklists
- preparar propuestas internas

No puede enviar nada a clientes sin aprobación.

## Nivel 2 — Edición interna

Puede editar archivos internos solo si el agente tiene permiso.

Ejemplos:

- mejorar documentación
- ordenar memoria
- actualizar estado de una tarea
- completar reportes internos

## Nivel 3 — Código y automatización segura

Puede proponer o trabajar en rama segura.

Requiere aprobación para:

- aplicar cambios finales
- conectar credenciales
- activar workflows
- modificar sistemas reales

## Nivel 4 — Acciones sensibles

Siempre requiere aprobación de Dirección.

Incluye:

- producción
- clientes
- precios
- bases de datos
- pagos
- credenciales
- envíos reales
- publicación externa
- cambios legales o contractuales

## Nivel 5 — Bloqueo total

No puede ejecutarse automáticamente.

Incluye:

- borrar bases de datos
- eliminar repositorios
- compartir credenciales
- enviar contratos sin revisión
- gastar dinero en APIs o servicios
- scraping riesgoso o masivo
